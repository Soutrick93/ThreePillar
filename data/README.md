# Input data

Place the input files here, under the exact names below. All are from public
resources. None are tracked in the repository.

| File | Source | Notes |
|---|---|---|
| `almanac_synergy.csv` | DrugComb (drugcomb.org) | NCI-ALMANAC ZIP synergy scores |
| `9606.protein.links.v12.0.txt` | STRING v12 (string-db.org) | human PPI links |
| `9606.protein.info.v12.0.txt` | STRING v12 | protein to gene-symbol map |
| `interactions.tsv` | DGIdb (dgidb.org) | drug-target interactions |
| `all_data_15_09_26.tsv` | SIGNOR (signor.uniroma2.it) | directed causal network |
| `nci60_expr.txt` | CellMiner (discover.nci.nih.gov/cellminer) | NCI-60 composite expression |
| `oneil_synergy.csv` | O'Neil 2016 / DrugComb | external validation screen |
| `CRISPRGeneEffect.csv` | DepMap Public 26Q3 (depmap.org) | Chronos gene-effect (~497 MB) |
| `Model.csv` | DepMap Public 26Q3 | cell-line model metadata |

The results folder is created and filled automatically when you run the pipeline.
